# Парсер вакансий hh.ru (Course Project)

## Описание проекта

Данный проект представляет собой консольное приложение для получения, хранения и обработки вакансий с платформы **hh.ru**.  
Программа позволяет:

- получать вакансии по ключевому слову через API hh.ru;
- сохранять вакансии в файл (JSON по умолчанию);
- избегать дублирования вакансий;
- фильтровать вакансии по ключевым словам;
- сортировать вакансии по зарплате;
- получать топ N вакансий;
- работать с разными форматами хранения данных (JSON, CSV, TXT — заглушка);
- взаимодействовать с пользователем через консоль.

Проект реализован в соответствии с принципами **ООП**, **SOLID**, **PEP 8** и покрыт тестами с использованием **pytest**.

## Основной функционал
### Работа с API
- Используется абстрактный класс BaseAPI
- Реализован класс HeadHunterAPI
- Приватный метод подключения к API
- Проверка статус-кода ответа
- Получение вакансий в виде списка словарей

### Работа с вакансиями
- Класс Vacancy с использованием __slots__
- Минимум 4 атрибута
- Приватные методы валидации данных
- Магические методы сравнения вакансий по зарплате

### Работа с файлами
- Абстрактный класс BaseStorage
- Реализация JSONStorage:
  - файл не перезаписывается при каждом запуске;
  - исключается дублирование вакансий;
  - имя файла — приватный атрибут с значением по умолчанию;

- Дополнительные хранилища:
  - CSVStorage
  - TXTStorage (заглушка под будущее расширение)

### Интерфейс пользователя
- Консольное взаимодействие
- Человекочитаемый вывод
- Возможность:
  - задать поисковый запрос;
  - получить топ N вакансий;
  - отфильтровать вакансии по ключевым словам.

## Установка и запуск

### 1. Клонирование репозитория

```
git clone <URL_РЕПОЗИТОРИЯ>
cd project
```

### 2. Создание виртуального окружения
```
python -m venv .venv
.venv\Scripts\activate   # Windows
```
# source .venv/bin/activate  # Linux / macOS

### 3. Установка зависимостей
```
pip install -r requirements.txt
```
### 4. Запуск приложения
```
python main.py
```
### Запуск тестов
```
pytest
```
Проверка покрытия кода:
```
pytest --cov=src --cov=api
```
Проверка стиля кода
```
flake8 .
```
В проекте используется файл .flake8, исключающий проверку виртуального окружения и служебных каталогов.
